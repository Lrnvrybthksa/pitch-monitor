How it works

Tap (or play) each bass note. It tells you if you were early, late or on time. Timing uses the offset from the Rhythm tab’s “clap along to set the timing”, so set that once for best results. Start slow, then raise the speed when you get 8 in a row.

Drum rhythm coach

Practice one drum at a time with the groove: the kick, the snare, the hi-hat, or kick and snare together. Good for feeling where each part sits.

The count is on top. Each row is a drum; the part you are practicing is bright. The light follows the beat.

–
Tips

Start with the kick at 75% speed, then the snare, then the hi-hat. When you can get 8 in a row, raise the speed. In "Kick and snare", tap the left pad for the kick and the right pad for the snare, like two hands on a table. Use wired headphones or the speaker; Bluetooth adds delay.
